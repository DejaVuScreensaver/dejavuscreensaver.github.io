How to open it.

DejaVuScreensaver is not signed or notarized yet. macOS may block the first launch even when you download it from the official GitHub repository.

Apple’s official security guide ↗
  1. 1
    Move it to Applications

    Open the DMG, drag DejaVuScreensaver into Applications, then try to open it once.

    DejaVuScreensaver
    DejaVuScreensaver
    →
    Applications
  2. 2
    Open Privacy & Security

    In System Settings, select Privacy & Security and scroll to Security.

    System Settings
    Search

    Privacy & Security
    Location Services›Contacts›Photos›
    Security
    Allow applications fromApp Store and identified developers
  3. 3
    Choose Open Anyway

    In the Security section, click Open Anyway. The button appears after the blocked launch.

    Security

    “DejaVuScreensaver” was blocked from use because it is not from an identified developer.

    Open Anyway
    Allow applications from◉ App Store and identified developers
  4. 4
    Confirm Open

    Choose Open in the warning, then authenticate if macOS asks. You only do this once.

    Open “DejaVuScreensaver”?

    macOS cannot verify the developer of this app. Are you sure you want to open it?
