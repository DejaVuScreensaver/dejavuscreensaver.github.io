  1. 0.4.0 Oct 13, 2026 Build 24

    Foundation

    Initial public preview

    • Native macOS slideshow with direct PhotoKit integration.
    • Album selection, favorites and capture-date filters.
    • Static and Ken Burns presentation modes.
    • Keyboard navigation, pause/resume, and photo metadata overlays.
    • DMG distribution for Apple Silicon, requiring macOS 14 (Sonoma) or later.
    View release ↗
  2. 0.5.0 Oct 15, 2026 Build 25

    Interface & playback

    Settings & playback

    • Redesigned SwiftUI settings with a macOS-style sidebar.
    • Unified album selection and filters with a live photo count.
    • Capture-date filtering between two dates.
    • Added Fade transitions and continuous Ken Burns motion.
    • Simplified exit behavior and automatic playback suspension while the display is asleep.
    View release ↗
  3. 0.6.0 Oct 19, 2026 Build 26

    Offline geodata

    Location & offline geodata

    • Added a minimap with animated zoom for geotagged photos.
    • Offline place-name resolution: nearby city, region, or country.
    • Location-only filtering and chronological playback order.
    • Custom calendar navigation and configurable 12/24-hour clock formats.
    • Simplified filter composition: all enabled conditions must match.
    View release ↗
  4. 0.7.1 Oct 22, 2026 Build 28

    Geographic filters & distribution

    Geographic filters & signed distribution

    • Country and radius-based geographic filtering.
    • Interactive map picker with place search and coordinate entry.
    • Radius visualization with metric and imperial units.
    • Developer ID signing, Hardened Runtime, and Apple notarization.
    • Fixed Photos authorization in Developer ID builds.
    View release ↗
  5. 0.7.2 Oct 23, 2026 Build 29

    Compatibility & security

    Universal binary & security hardening

    • Universal macOS binary supporting arm64 and x86_64.
    • Independent lock-state verification before dismissing slideshow covers.
    • Immediate removal of photos and metadata during lock handoff.
    • Cancellation of pending image requests and playback controls while the security cover is active.
    • Improved multi-display coverage during lock transitions.
    • Fixed legacy viewing-history migration and deletion.

    • Scheduled background checks with a sidebar availability badge.
